# Reaper prototype

> **Plywood REV3 is current.** Use [the single plywood DXF](Workshop_Plywood_REV3/REAPER_PLYWOOD_6mm_8x4ft_REV3.dxf) and [shop instructions](Workshop_Plywood_REV3/SHOP_INSTRUCTIONS.md). It contains 32 aircraft pieces and 5 test pieces for nominal 6 mm stock. Cut the test layer first. The guide, CAD, part lists and paper motor templates now match REV3. Do not use the older 33-piece sheet.

Read the [buildability audit](Buildability_Audit.md) before building. Motor screw access is corrected. Foam construction and actual control-joint fit still need trials and corrections; strength, balance and propulsion remain unqualified. The complete kit is not yet a proven beginner build or a flight-approved design.

![Current aircraft with three-blade propeller and fixed gear](Illustrations/Assembly.png)

Start with the [illustrated build guide](Build_Guide.pdf) or its [text version](Build_Guide.md). The guide has a front-page performance summary, exact part galleries, numbered assembly stages, wiring diagrams and pass/fail setup checks. Use only this package's cutting and print files.

Each wooden part has a consistent natural wood shade in the assembly pictures. Shades help distinguish adjacent pieces; they do not specify different wood species or finishes.

REV3 changes motor parts FMF/FMT and removes FMGB. All other 110 individual STEP files and all 14 new print meshes are unchanged. The 179-page paper set has corrected motor templates; foam outlines remain reference geometry pending the forming work in the audit.

All geometry uses millimetres. Three plain wooden legs connect the body to the owned wheel/axle assemblies; the owner will handle attachment details. Wheel dimensions and offsets remain workshop measurements. The propeller shown is an illustrative purchased-hardware reference, not a printable design. Digital verification does not establish structural strength, measured CG, propulsion margin or flight readiness.
