# Assembly reference

[Complete positioned assembly](MQ9_Revised_Assembly.step) · [Illustrations](Illustrations/README.md) · [Nose bypass](Nose_Bypass_Build.md)

Axes: X across the wings, Y toward the tail, Z up. Nose datum is Y=-439.65 mm. Battery travel and service access are detailed in the Manufacturing Team guide.

REF components are purchased-equipment envelopes, not fabrication parts. The battery illustration uses one position within its adjustment range; choose the real position by weighing and balancing the completed aircraft.
