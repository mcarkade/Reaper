A26 has already been sent for a PLA fit test. Plywood is the planned conditional next option if the fit is correct. See [motor-mount notes](../Data/A26_Motor_Mount.md).

[Print_Names_and_Settings.csv](../Data/Print_Names_and_Settings.csv) retains the reference recipes for the other files. W means wall loops; GYR/RECT mean gyroid/rectilinear; SUP/NOSUP indicate reference support choice; L0p2 means 0.2 mm layers; B is brim width. Actual shop settings are not encoded in an STL. The unchanged upright ailerons are about 271 mm tall; the shop must fit them to its machine at unchanged scale.
