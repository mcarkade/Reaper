# Print order

N1 nose is already printed: do not print it again. Print FIT_COUPON first and measure the owned rod/spoke and actual slots. Print 14 new parts from `Individual/`; three optional grouped jobs in `Batches/` reduce machine setup time. Use the slicer settings and exact STL hashes in `Data/Print_Slices.json`. Check the real printer envelope and supports, especially the tall ailerons/rails. Batch jobs can be replaced with individual reprints. A09/A37 gear fittings are excluded until the purchased gear is measured.
