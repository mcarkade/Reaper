Print on A4 at **Actual Size /100%**. Disable Fit, Shrink and automatic scaling. Measure the **100 x20 mm** rectangle before cutting. Align matching marks and the indicated overlap.

Parts that fit one page remain whole. The new battery tray fits on one page with the other 3 mm parts. Each pattern set is printed once; follow its quantity labels for repeated pieces. Gear/service openings in foam are finished after forming, as shown in the body guide.
