Use ASA, six walls, 100% rectilinear infill, 0.2 mm layers, 0.4 mm nozzle and an 8 mm brim; put its forward broad face on the bed as supplied. Confirm the actual ASA spool and suitable enclosed printer before manufacture. Use its manufacturer's temperature profile; the Prusament reference is not permission to treat an unidentified spool the same way. Check flat seating and inspect layers and all hole/slot regions. Reference slicing is not actual print acceptance.

Verify the actual wood thickness, rear-frame notch fit, 19 mm opposite-hole spacing and motor-base seating before bonding or powering. Use measured metal-washer contact/driver access and a screw length selected from the actual plate/washer stack and usable motor thread depth. Qualify ASA-to-wood bonding and the printed mount under thrust, torque, vibration and actual temperature; stop for cracks, clamp relaxation, warping or bond movement. No flight load or safe operating temperature has been established. The corrected internal DXF is a geometry reference, not a laser job or a user delivery file.
