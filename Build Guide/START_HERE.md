# Start here

Open [Complete Build Guide](Complete_Build_Guide.pdf) for the full illustrated manual. The separate [airframe guide](01_Airframe_Manufacturing_and_Assembly.pdf) and [electronics guide](Electronics_Build_Guide.pdf) cover each team's work.

Use [Build_Record.csv](Build_Record.csv) to record measurements and physical checks. Supporting drawings, parts lists and the verification summary are grouped in [Reference](Reference).

Send your teammate [MQ9_Manufacturing_Rev1.zip](https://github.com/mcarkade/Reaper/releases/download/rev1/MQ9_Manufacturing_Rev1.zip). Actual-size cutting patterns are in [Manufacturing/Print_Templates](../Manufacturing/Print_Templates) and inside the ZIP. Print at Actual Size / 100% and measure the calibration marks. Overview drawings are not cutting templates.

This is a prototype fabrication handoff. Complete shop coupons, dry fitting and the documented physical checks. The provisional balance station and owned propulsion combination still need physical assessment before flight.
