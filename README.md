# Reaper RC build

Fabrication files and illustrated instructions for the 2-metre MQ9 model.

## Current work: N1 nose only

**[Download the simplified nose STL](Manufacturing/Nose_Print_N1/A59_Nose_N1_mm.stl)**. Print one in millimetres at 100%. Read the [nose instructions](Manufacturing/Nose_Print_N1/README.md) or [shop PDF](Manufacturing/Nose_Print_N1/Nose_N1_Print_Guide.pdf).

The design is being simplified around a wood skeleton and foamboard covering. Landing gear is removed from the intended new design. N1 restores the nose tip and removes the added cover-screw holes and large service notch. Only this nose is released for the current printing order. The old 42-piece print set, landing-gear instructions and mass/CG calculations are on hold while the rest is redesigned.

**[Download the nose-only package](https://github.com/mcarkade/Reaper/releases/download/nose-n1/MQ9_Nose_N1.zip)**.
