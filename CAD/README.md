# Current CAD

Reaper_R5_Assembly.step is the named R5G assembly: 66 original part identities plus two preserved whole carbon rods. Parts contains finished world-coordinate geometry; Stock_Blanks contains distinct laser stock; Secondary_Removal contains local finishing tools. A26 and A44 are current plywood parts. Earlier printed fit geometry is preserved in Archive_Fit_Prototypes, and obsolete secondary operations in Archive_Secondary_R5F.

Native assembled foil/skin IDs differ from the FW manufacturing-wrap IDs. N1 is an owned printed nose reference without a corresponding native part in this source set; no mapping is invented. Accepted source foam skins are unchanged reference geometry: the guide requires local internal relief against reinforced A44 and actual board thickness. Raw topology, a clean compound or a printable mesh does not prove physical fit, insertion, retention, material strength or flight readiness.
