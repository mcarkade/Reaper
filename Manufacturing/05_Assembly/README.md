# Assembly reference

Open [the revised assembly](MQ9_Revised_Assembly.step) in a STEP-compatible CAD viewer to inspect part positions.

Follow the [Manufacturing Team guide](../../Build%20Guide/01_Airframe_Manufacturing_and_Assembly.pdf) for build order. Use the [illustrations](Illustrations) and [nose joint instructions](Nose_Bypass_Build.md) for detailed views.

The assembly is a fit reference, not one printable object. Use the individual cutting and print files. Coordinate electronics access before closing the body.
