# Actual-size A4 templates

Open a PDF below, then select **Download raw file** to save it.

| Template | Pages |
|---|---:|
| [5 mm plywood](Plywood_5mm_A4_Tiles.pdf) | 5 |
| [3 mm plywood](Plywood_3mm_A4_Tiles.pdf) | 1 |
| [2.5 mm plywood](Plywood_2.5mm_A4_Tiles.pdf) | 1 |
| [Foam](Foam_1to1_A4_Tiles.pdf) | 23 |
| [Optional tail forming tools](Tail_Forming_Profiles.pdf) | 2 |

1. Print on A4 at **Actual Size / 100%**. Disable Fit, Shrink and automatic scaling.
2. Measure the **100 × 20 mm** calibration rectangle before cutting.
3. Follow printed part IDs and tile order. Align paired registration marks and overlap the indicated areas.

Parts that fit one page remain whole. For longer parts, follow tile labels rather than assuming PDF page order is assembly order. The foam set includes an index/calibration page; the tail-tool set includes an instruction page.
